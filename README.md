# ☕ Curso de Java Completo: Programação Orientada a Objetos & Ecossistema Spring

Repositório criado para documentar toda a minha jornada de desenvolvimento na linguagem Java. Este espaço centraliza anotações conceituais, códigos produzidos durante as aulas, exemplos práticos e resoluções de exercícios propostos.

🚀 **Desenvolvido com tecnologias modernas e atualizadas: Java 25 & Spring Boot 4**

---

## 🎯 Objetivos do Repositório
* Construir uma base sólida em **Programação Orientada a Objetos (POO)**.
* Aplicar boas práticas de arquitetura e design de software utilizando **Diagramas UML**.
* Desenvolver APIs backend robustas e escaláveis com o ecossistema **Spring**.
* Praticar a escrita de código limpo, estruturado e versionamento profissional via Git/GitHub.

---

## 🗂️ Grade Curricular & Tecnologias Aprendidas

### ☕ Core Java & Paradigmas
* **Fundamentos de POO:** Classes, atributos, métodos, construtores, sobrecarga e encapsulamento.
* **Estruturas de Dados:** Arrays (vetores), matrizes bidimensionais e manipulação de coleções (`List`).
* **Tópicos Avançados:** Enumerações, composição de objetos, herança, polimorfismo e interfaces.
* **Robustez de Código:** Tratamento de exceções personalizado (`try-catch` e estruturas customizadas).
* **Java Moderno:** Generics, programação funcional, expressões lambda e Stream API.
* **I/O:** Manipulação de arquivos (leitura e escrita automatizada no sistema).

### 🌐 Interface Gráfica & Persistência de Dados
* **JavaFX:** Construção de interfaces gráficas (GUI) ricas e funcionais.
* **JDBC:** Conexão nativa e execução de consultas baseadas em SQL.
* **Bancos de Dados:** Integração prática com bancos de dados relacionais e NoSQL (MongoDB).

### 🍃 Ferramentas & Frameworks Corporativos
* **Maven:** Gerenciamento automatizado de dependências e builds do projeto.
* **Spring Boot 4:** O principal framework Java para desenvolvimento backend de nível comercial.
* **JPA / Hibernate:** Mapeamento Objeto-Relacional (ORM) avançado.
* **Spring Data JPA & MongoDB:** Abstração e otimização das camadas de acesso a dados.
